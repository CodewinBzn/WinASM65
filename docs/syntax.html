Syntaxe de l'assembleur WinASM65

La référence complète du langage accepté par WinASM65 : la syntaxe 6502 standard de MOS, plus les formes courantes de ca65, asm6 et NESASM. Les exemples supposent définis les noms qu'ils utilisent sans les déclarer.

Structure d'une ligne

Une ligne contient au plus une instruction ou une directive, éventuellement précédée d'un label et suivie d'un commentaire. L'indentation n'a pas de sens : la ligne est rognée avant d'être lue. Les mnémoniques, les directives et les noms ne distinguent pas les majuscules des minuscules.

Start:                  ; un label seul sur sa ligne (deux-points obligatoire)
loop    lda $2002,x     ; un label devant une instruction (deux-points facultatif)
Table:  .byte 1, 2, 3   ; un label devant une directive
        bne loop

Une ligne est l'une des formes suivantes, dans cet ordre de reconnaissance :

FormeExemple
Portée locale{ … }
Label anonyme-, ++ lda #0
Origine*= $C000
ConstanteN EQU 5, N .equ 5, N .set 5, N = 5
Réservationbuffer .res 16
Label + directiveData: .word $1234
Directive.org $8000
Label seulReset:
Instruction (avec label éventuel)loop: lda #1
Appel de macrovblank wait1, $2002

Toute autre ligne est une erreur de syntaxe.

Commentaires et chaînes

Un commentaire commence au premier ; qui n'est pas à l'intérieur d'une chaîne ou d'un caractère. .byte "a;b" et cmp #';' gardent donc leur point-virgule. Une apostrophe isolée, comme dans ; wait for 2 VBlank's, n'ouvre rien.

Une chaîne s'écrit entre guillemets doubles et peut contenir des virgules, des points-virgules et des séquences d'échappement :

SéquenceOctet
\n \r \t \0$0A $0D $09 $00
\\ \" \'la barre oblique, le guillemet, l'apostrophe
\xNNl'octet hexadécimal NN

Toute autre séquence, une chaîne non terminée ou un caractère au-delà de $FF est une erreur. Les noms de fichiers de .include et .incbin sont lus tels quels, sans échappement, pour qu'un chemin Windows garde ses barres obliques inverses.

Nombres et caractères

% n'est un préfixe binaire que là où une valeur est attendue : 7%10 est un modulo, qui vaut 7. Les formes 0x10 et 0b1010 du C ne sont pas acceptées : elles produisent une erreur, et non plus une valeur fausse.

Expressions

Une expression combine nombres, caractères, noms et opérateurs. Par ordre de priorité décroissante :

PrioritéOpérateursSens
11 (unaires)< > + - ~ !octet bas, octet haut, signe, complément, non logique
10* / %multiplication, division, modulo
9+ -addition, soustraction
8<< >>décalages
7< > <= >=comparaisons
6== = != <>égalité, différence
5&et binaire
4^ou exclusif
3|ou binaire
2&&, ANDet logique
1||, ORou logique

Les parenthèses regroupent. AND, OR, TRUE et FALSE ne sont des mots-clés que comme mots entiers : origin ou and_mask sont des noms. # marque l'adressage immédiat devant l'opérande.

Une expression qu'on ne peut pas évaluer est une erreur signalée à sa ligne, au lieu de devenir 0 sans rien dire :

  • un caractère inconnu (lda #$12#) ;
  • une forme incorrecte : deux valeurs côte à côte, un opérateur sans opérande, des parenthèses déséquilibrées ;
  • une division par zéro, y compris quand elle n'apparaît qu'après la résolution d'une référence avant ;
  • un nombre trop grand.

Compteur de programme

* en position d'opérande vaut l'adresse de la ligne en cours. Entre deux valeurs, * reste une multiplication. *= expr fixe l'origine, comme .org.

*= $C000
        jmp *           ; boucle sur place : 4C 00 C0
Here:   .word *+2       ; l'adresse qui suit ce mot
        lda #2*3        ; 6, une multiplication

Une expression mise en attente (parce qu'elle lit un nom défini plus loin) garde l'adresse de la ligne où elle est écrite.

Labels

Labels globaux

Un nom commence par une lettre ou _, suivi de lettres, de chiffres ou de _. Seul sur sa ligne, il prend un deux-points ; devant une instruction ou une directive, le deux-points est facultatif. Un label global qui prend une adresse ouvre une nouvelle portée pour les labels locaux.

Labels locaux : @nom

Un nom qui commence par @ appartient au dernier label global. Le même nom peut donc resservir dans la routine suivante :

Clear:
        ldx #0
@loop:  sta $0200,x
        inx
        bne @loop
        rts
Copy:
@loop:  lda $0300,x     ; un autre @loop
        dex
        bne @loop

Une constante ou une réservation (.res) n'ouvre pas de portée. Dans une macro ou un bloc .rep, un label local appartient à l'expansion : chaque appel a le sien. Référencer un label local d'une autre portée, ou en définir un avant tout label global, est une erreur.

Labels anonymes : - et +

Comme dans asm6, une ligne qui commence par - ou + définit un label anonyme. Elle peut être seule ou suivie d'une instruction. Un opérande qui n'est que - désigne le plus proche label - en arrière ; un opérande qui n'est que +, le plus proche label + en avant.

        ldx #8
-       dex
        bne -           ; retour à la ligne "-"
        beq +
        nop
+       rts             ; cible de "beq +"

Les suites de longueurs différentes sont des labels distincts : bne -- vise la ligne -- la plus proche, pas le deuxième -. Un label anonyme introuvable est signalé (« No anonymous label '+' after this line »).

Les labels locaux et anonymes ne sont jamais exportés (fichiers .symb, modules) : deux unités d'un même projet ne résolvent pas leurs + l'une avec l'autre.

Portées lexicales

{ et } ouvrent et ferment une portée : les noms définis à l'intérieur n'en sortent pas.

Constantes

FormeRedéfinissableUsage
N = exprouivaleur de travail, compteur dans un .rep
N .set exprouimême chose, à la manière de ca65
N EQU expr, N .equ exprnonconstante : une seconde définition avec une autre valeur est une erreur (la même valeur est acceptée)

Les directives .equ et .set ne s'emploient qu'après un nom ; seules, elles sont une erreur.

Une constante peut lire un nom défini plus loin : elle est alors calculée dès que ce nom est connu.

Directives

Une directive commence par un point. Une directive inconnue est une erreur (elle était ignorée sans rien dire).

Données

Les arguments sont séparés par les virgules qui ne sont ni dans une chaîne, ni dans un caractère, ni entre parenthèses. Une valeur qui ne tient pas dans son champ est une erreur, pas une troncature. Le nombre d'octets de .dsb, .pad et .align doit être connu à la ligne même.

Assemblage conditionnel

.if PAL
        lda #50
.elseif DENDY
        lda #50
.else
        lda #60
.endif

.if expr, .ifdef nom, .ifndef nom, .elseif expr, .else, .endif, jusqu'à 255 niveaux d'imbrication. La condition d'un .elseif n'est lue que si aucune branche précédente n'a été prise ; un .else ou un .elseif après un .else est une erreur.

Diagnostics

DirectiveEffet
.error "message"Erreur à cette ligne : le build échoue.
.warning "message"Avertissement : le build continue.
.assert expr[, "message"]Erreur si l'expression est fausse. Si elle lit un nom défini plus loin, elle est vérifiée une fois l'unité complète.

Dans une branche conditionnelle non assemblée, ces directives ne font rien.

Modules et fin

.export a, b et .import sym[, module] déclarent les noms échangés entre modules relogeables (voir docs/format-module.md). .end arrête l'assemblage du fichier.

Macros et répétitions

.macro vblank label, register
label:  bit register
        bpl label
.endmacro           ; ou .endm

        vblank wait1, $2002
  • .macro nom p1, p2 … .endmacro (alias .endm) définit une macro ; elle s'appelle par son nom suivi des arguments.
  • Les paramètres sont remplacés comme des mots entiers : un paramètre nommé x ne réécrit pas tax.
  • Les arguments sont séparés comme ceux d'une directive. S'il y en a plus que de paramètres, le dernier paramètre reçoit tout le reste : get ($10),y passe l'opérande entier à une macro à un paramètre.
  • .rep n … .endrep (alias .rept, .endr) répète un bloc n fois.
  • Les macros et les répétitions ne s'imbriquent pas. Chaque expansion a ses propres labels locaux.

  • Choix de la page zéro. Une valeur connue entre 0 et 255 prend la forme page zéro quand l'instruction en a une. Une référence avant prend la forme absolue, sauf si l'instruction n'existe qu'en page zéro (stx nom,y, sax, rmb…).
  • A comme opérande. A n'est l'accumulateur que pour une instruction qui a cette forme (ASL, LSR, ROL, ROR ; INC et DEC sur 65C02). Ailleurs, c'est un nom : lda A lit le symbole A.
  • Formes inexistantes. Une instruction écrite dans un mode qu'elle n'a pas est une erreur (« STX does not support absolute,X addressing »). Avant, l'octet $FF était émis sans aucun message.
  • Branches relatives. Un déplacement hors de -128…127 est une erreur, signalée à la ligne de la branche même quand la cible est définie plus loin.

Ce qui n'est pas pris en charge

  • Directives sans point (org, db à la manière d'asm6) : elles entreraient en collision avec les labels et les macros. Seul EQU s'écrit sans point.
  • .dc.b / .dc.w (style 68000) : utiliser .byte / .word.
  • .proc, .scope, .segment de ca65 : les portées sont { } et les labels locaux ; les segments se décrivent dans config.json.
  • Labels locaux .nom : le point introduit les directives, d'où le choix de @nom.
  • Plusieurs instructions par ligne, et les commentaires * en colonne 1 ou /* */.
  • Fonctions dans les expressions (.defined(), .sizeof()…).
  • Macros et .rep imbriqués.
